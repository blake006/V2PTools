## 本版重点：图标与进程名不再显示成 Electron

上一版 exe 关闭了资源写入（`signAndEditExecutable: false`），导致：

- 任务管理器里进程显示成 **Electron**、图标是默认的原子标志
- 文件属性里产品名/版本号也是 Electron 的

1.0.1 起改为打包后由 rcedit 写入图标与版本资源，现在：

- 任务管理器显示 **V2PTools**，描述「代理池体检 + 系统代理工具」
- 专属图标（V + 代理链路 + 健康节点），16px 任务栏尺寸单独做了简化版
- 文件属性版本号 1.0.1，与文件名一致

## 专属图标

按项目特点重新设计，不再沿用上游 IPHealth 的盾牌：

- 白色 **V** = V2PTools 首字；左臂**断续**表示请求经代理中转，右臂**实心**表示直达目标
- 顶点**青绿节点** = 链路健康（对应健康度评分，绿=优秀）
- 深空蓝圆角底板 + 极淡隧道环，16px 下自动隐去细节

## 打包与版本

- `npm run dist` 一条命令出 zip + 单文件便携版，内部自动完成 rcedit 写资源
- 版本号统一 `1.0.X` 顺次递增：`npm run bump` 会同步 `package.json` 与 NSIS 脚本

## 功能（与 1.0.0 相同）

导入代理 → 批量体检 → 选中节点 → 一键设为系统代理。系统代理用独立 mihomo 内核（单 mixed 端口），
与检测内核完全隔离；改注册表前完整备份，关闭/退出/崩溃/强杀四种情况都会还原，且绝不覆盖用户手动设置的代理。
