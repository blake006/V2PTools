## 新增：分流方式（调节代理走向）

以前系统代理只有「全部走节点」一种。1.0.2 起工具栏「系统代理」右侧多了一个下拉箭头，
可以在三种分流方式之间切换，**立即生效，端口和系统代理设置都不动**（只重启网关内核）：

| 模式 | 行为 |
|---|---|
| **全局代理**（默认） | 所有流量都走节点，与之前行为一致 |
| **绕过大陆** | 国内域名 / 国内 IP 段直连，其余走节点 —— 日常最实用 |
| **仅名单代理** | 只有名单内的站点走节点，其余全部直连 |

设置弹窗里也能选，两处状态同步。

### 规则是内置的，运行时不联网

规则数据来自 [Loyalsoldier/clash-rules](https://github.com/Loyalsoldier/clash-rules)：

- CN 直连域名 **110,187** 条
- CN IP 段 **10,013** 条
- 被墙域名 **4,449** 条

构建时由 `npm run fetch-rules` 转成 mihomo rule-provider 格式，随安装包一起分发。
不需要下载 geoip/geosite 数据，也不需要联网更新，断网可用。

> 实现细节：mihomo 只允许 rule-provider 指向数据目录内的子路径，所以启动时会把规则复制到
> `<userData>\gateway\rules\`，配置里用 `./rules/*.yaml` 相对引用。

## 其他

- 状态徽标改为显示分流方式（`系统代理 · 绕过大陆`），鼠标悬停可看出口节点
- 修了网关测试里「停止后端口释放」偶发失败（内核退出后 socket 短暂 TIME_WAIT，改为轮询等待）

功能与安全机制（备份还原、崩溃恢复、绝不覆盖用户手动代理）与 1.0.1 完全一致。
